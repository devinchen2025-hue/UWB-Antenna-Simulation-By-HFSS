# D44 厚板 PIFA 几何电流路径/腔体边缘耦合/馈点联动优化报告

日期：2026-05-13

## 目标

- 结构约束：继续保留 8 mm 厚板、低成本 PCB 工艺；优先使用顶层蚀刻槽、短路墙/边镀或过孔墙、开口边耦合墙、馈点位置和几何电容馈电，不引入独立 L 金属臂。
- S11 目标：`S11 <= -10 dB`。
- 增益目标：Theta `45..90 deg`，最佳连续 `270 deg` 方位窗口内 `GainTotal >= -5 dBi`。

## 本轮优化路径

1. 在 #100 高增益厚板 PIFA 基准上，继续拉长/缩短电流路径、调整短路墙宽度、侧墙起点、开口边耦合墙高度和馈点位置。
2. 导出 #100 与 #126 的复阻抗后，确认端口呈高阻抗强感性：#100 约 `130.4 + j141.2 ohm`，#126 约 `142.6 + j184.8 ohm`。
3. 新增顶层蚀刻隔离的几何电容馈电岛，用小间隙耦合到主辐射片，尝试用低成本几何电容抵消感抗。
4. 在 #136/#142 附近细扫馈电岛间隙、岛尺寸、馈点沿长度方向位置，以及横向 `feed_v` 偏置。

当前最佳候选为 `#142 h8p0_l14p8_capfeed_f1365_gap0p10_i1p2x3p0`：

- `S11 = -3.221 dB`，未达到 `-10 dB`。
- 最佳 270deg 方位窗口最小 `GainTotal = -4.252 dBi`，达到 `>= -5 dBi`。
- 8 GHz 复阻抗约 `141.7 + j131.8 ohm`。相对 #100，几何馈电岛降低了一部分感抗，但输入电阻仍显著高于 50 ohm。

## 工程判断

- 仅靠同相位中心厚板 PIFA 的几何电流路径、边缘耦合和馈点联动，本轮没有找到 S11 与低仰角增益同时达标点。
- 强化几何电容馈电可以把 S11 从 #100 的 `-2.984 dB` 改善到 #142 的 `-3.221 dB`，但改善量只有约 `0.24 dB`；继续加强耦合虽然可到约 `-4.07 dB`，会把低仰角增益拉到 `-7 dBi` 量级。
- 横向偏置馈点会破坏最佳 270deg 方位窗口内的低仰角覆盖，不适合作为主优化方向。
- 端口仍处于高阻抗感性状态，说明当前 8 mm 同相位中心厚板 PIFA 的可调几何自由度不足以自然逼近 50 ohm。

## 下一步建议

- 如果必须坚持 `S11 < -10 dB` 且低成本量产，建议转向真正板边低仰角单元/板边 IFA/PIFA，或者允许一个低成本印刷/离散匹配网络参与。
- 如果必须保持当前同相位中心厚板 PIFA，则建议把 #142 作为增益达标的物理基准，后续用外部匹配网络或系统级校准处理阻抗缺口，不再继续对同一几何集合盲扫。
- 系统级测角验证仍建议采用“可校准阵列 + 真实低仰角覆盖单元 + 极化 LUT”的组合，而不是继续只在当前厚板 PIFA 几何上硬拧 S11。
